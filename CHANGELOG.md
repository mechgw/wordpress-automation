# Changelog

All notable changes to this project will be documented in this file.

The project follows Semantic Versioning.

## [2.8.0] - 2026-09-05

### Added

- Initial public repository baseline for the existing Google Apps Script project.
- Apps Script manifest, Search Console integration, GA4 automation and WordPress bridge source files.
- Repository workflow documentation.
- CI checks for manifest validity, Apps Script syntax and committed secrets.
- Release Drafter configuration for automated draft release notes.

### Notes

- This release establishes the versioned baseline. It is not intended to change the runtime behaviour of the existing Apps Script project.
- Deployment to Google Apps Script remains manual.
